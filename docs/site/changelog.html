0.7.0 — 2026-10-04

GitHub release: v0.7.0

Added

  • Showreel (package/showreel/): a 15-second, 60 fps motion piece in 16:9 and 9:16 cuts, cut on a 120 BPM beat. One hand-written Canvas2D file, a synthesized soundtrack, and a Bun + headless Chromium + ffmpeg capture that caches fonts and deletes its frames. Watch it: 16:9 · 9:16.
  • Simplified Technical English skill: opt-in ./install.sh --with-ste fetches 0xpili/simplified-technical-english at a pinned commit (referenced, not vendored). Forced updates are staged and validated before they replace the active checkout.
  • package/ste-check/: a bun port of the upstream checker, byte-identical on 366 corpus runs and 16 golden fixtures.
  • STE docs gate in scripts/verify-all.sh: a per-doc error ratchet over QUICKSTART.md, CONTRIBUTING.md, SECURITY.md, and docs/*.md. New docs must have zero errors. See docs/ste.md.

Changed

  • QUICKSTART.md rewritten in STE (5 → 0 structural errors).
  • OpenCode writing agents allow the simplified-technical-english skill. Locked lanes and the EC2 profile are unchanged.

Fixed

  • A wire-multi-backend.sh backup-name collision copied a foreign Kimi dir into the repo and failed every install-surface COPY record.
  • ripgrep is an explicit dependency. A missing rg now fails closed instead of skipping a credential-leak scan.
  • install-surface typecheck is green again. Doctor reports LaunchAgent records as UNAVAILABLE instead of sending them to the transform observer.
  • Test isolation: a vacuous backup check, the synthetic STE attribution in the private-path guard, and the proxy-live test's operator-log isolation.
Qualification boundary. A feature release, not the v1.1 clean-host milestone or a claim of end-to-end 1M sessions. The pin stays 9router@0.5.75. Per-attempt context enforcement and durable checkpoint recovery remain unqualified. The showreel is documentation media and changes no installer, doctor, lifecycle, or routing contract.

0.6.0 — 2026-09-19

GitHub release: v0.6.0 — Guided v4 operator flow

Added

  • Portable v4 hand-in-glove onboarding: optional personal profiles, private host bindings, dependency-aware organs, mounted-volume checks, and read-only project discovery with explicit enrollment.
  • Guided seven-step onboarding (Host, Projects, Providers, Combos, Organs/tools, Integrations, Review). The headless agent flow shares the TUI's actions and admission gates.
  • Exact-version 9router@0.5.75 capability adapter with live provider and model discovery, reviewed combo seating, and digest-bound cutover with rollback evidence.
  • Read-only operator health, install doctor integration, opt-in bounded metadata telemetry, and log inspection from the TUI or JSON CLI.
  • Optional session-policy admission checks and a shared seven-phase alchemical/Kosha header projection.

Changed

  • Temperance stays independently installable. Noesis/Cambium is an optional personal layer.
  • Onboarding uses sequential guidance with Enter actions. Blocked plans cannot be confirmed.
  • Scoped lifecycle updates and refreshed COPY provenance reconcile managed surfaces without counting unavailable transforms as installs.

Fixed

  • Unicode is preserved across routing, health, and log handoffs, and agent step arrays keep workflow order.
  • Successful admission diagnostics stay out of worker completion output, so blank responses cannot pass as model work.
  • Synthetic test homes are portable and isolated from the operator's personal policy, logs, and live catalog.

Security

  • OAuth proof and provider tokens stay out of plans, receipts, and telemetry. Logs are bounded, owner-only, and metadata-only.
  • Missing, stale, or unverified routing and context evidence holds admission. Prerequisite availability is never reported as runtime health.
Qualification boundary. Not the v1.1 clean-host milestone or end-to-end 1M sessions. 9router@0.5.75 is the only qualified pin (0.5.81 is held). Per-attempt context enforcement and durable checkpoint recovery are not qualified, and unsupported doctor transforms and generators stay explicitly unavailable.
