Part A — Install ./install.sh --with-spine

  1. Alias expands. SPINE_MODE=install forces CODEX_MODE, GSD_MODE, MANIFEST_MODE, and CLAUDE_MODE to install. OpenCode/Cursor stay on their defaults.
  2. Public surfaces still run. PAI templates, skill-cluster resolver, peon detect, CodeGraph init, OpenCode/Cursor templates, then scripts/install-spine.sh.
  3. Spine copies SoT. Codex UPS hooks from package/hooks/codex. Router copy including temperance-goal.mjs, gsd-rail-map.json, temperance-next-wave.mjs. Product symlink ~/.temperance_engine/product → this clone.
  4. GSD remotes land. gsd-command-install.mjs writes /gsd:* wrappers to Codex prompts, OpenCode command, and Grok commands. Includes /gsd:doctor and /gsd:goal. Does not vendor GSD 1.30.0.
  5. Manifest Zone + bridge. LaunchAgents for :8766 and :5173. Working directory is the live Manifest Zone with node_modules, not a bare repo tree.
  6. Pulse starts if bun exists. :31337 peon for phase messages. Non-phase may forward to Voice :8888. Auth failures classify as tts-auth.
  7. verify.sh last. Required files now include package/router/temperance-goal.mjs and package/manifest-zone/src/GsdDeck.tsx.

Part B — First session

  1. Picker, not a browser.setup If the session has no PAI mode, show native Codex/OpenCode tiles. Do not open Chrome or Safari.
  2. IAB after the pick.setup ChatGPT in-app browser to http://127.0.0.1:5173/?mode=…&view=…. Manifest Zone title. STATE / ROADMAP / GOAL cards.
  3. UPS compose.observe Only PromptProcessing emits additionalContext: classifier + temperance-rail + gsd-rail + pai-mode-offer + hook.receipt. SessionStartTe may hint /gsd:progress and ranker age.
  4. Observe / Think / Plan.plan Pulse peon packs fire on phase announces. Plan with /gsd:plan-phase or writing-plans if swarm-architect is missing. active_planner decides whether Goal text comes from ISA or STATE.
  5. Execute under lock.execute Next-wave approval required. Fleet uses te-dispatch-paid. temperance-next-wave.mjs writes the dual-fleet lock. A second gsd-executor swarm on the same [P] ids is forbidden for <2h.
  6. /gsd:goal.verify Writes .temperance/goal.json. Evaluator runs doctor / ISA probes. Fail → continue the same /gsd:*. Pass → stop. Not a new planner.
  7. Learn.learn Decisions stay in the project or task ISA. Manifest GOAL card updates from the bridge. Pulse learn pack plays if announced.
