# Pure Darwin spawn capability audit

`spawn-capability-audit.py` accepts trusted injected SDK excerpts and a trusted injected runtime-report callback. It neither reads source files nor loads libraries, resolves real symbols, invokes audited target functions, initializes attrs/actions, creates FDs, or spawns. A future loader-only point must be separately reviewed; library loading/resolution itself involves native runtime activity, so only absence of audited target-function calls can be claimed.

Initial exact6keys: sources,sdk_platform,sdk_arch,sdk_version,created_ns,deadline_ns. sources is an exact3key plain dict named spawn.h,sys/spawn.h,libSystem.tbd. Each exactbytes value<=64KiB and total<=256KiB before strict UTF8 decode. Three-source actual maximum is192KiB. Labels are bounded ASCII<=64; Darwin arm64/x86_64 profile only. Original signed64 monotonic anchors permit1..2s, no renewal. Before/after callback checks hold if late, backwards or invalid; synchronous callbacks cannot be preempted. Source text is detached, not authenticated SDK provenance or a filesystem intake implementation.

Conservative literal profile matches one opaque void* typedef each for attrs/actions, fixed nine int-return function declarations, short setflags, three exact Darwin flag values, and nine link-stub symbol names. This is not a C/TBD parser or a check of all prototypes/architecture conditions/comments. Source origin/version/architecture is trusted owner metadata; snippets cannot establish runtime ABI. The exact whitelist is posix_spawn; posix_spawnattr_init/destroy/setflags/getflags; posix_spawn_file_actions_init/destroy/adddup2/addclose. No arbitrary symbol/path selectors.

Injected report exact7keys platform,arch,version,pointer_bits,short_bits,symbols,python_attr_flags_exposed. symbols exactnine bools. Matching declared platform/arch and64-bit pointer/16-bit short required; missing/false/malformed symbol holds. SDK/runtime version labels equal means same-label-unproved; difference means different-label-compatibility-unknown, not ABI incompatibility. Python attr-flag reporting is diagnostic: true does not prove START_SUSPENDED/CLOEXEC_DEFAULT behavior.

One audit attempt only, intent before callback, first hold sticky and duplicate cannot rerun observation. Fixed reasons never serialize exceptions or call __str__. Reported availability describes a successful past report; receipt held after a later duplicate is never permission. Immutable receipt always reports native_readiness,unknown_fd_closure_proven,execution_authorized,capacity_authorization,inference_authorized false. No capacity/resource/parent-chain/stop/unknown-FD exclusion proof, v2 private actor contexts or Build activation follows.

Future real loader/ABI/native stopped semantics and exact source snapshot provenance remain separate. Existing v1 helper bytes are unchanged. Future v2 role schemas preserve both original reservation responses and clock anchors; this audit does not implement them.
