# Dedicated Darwin model-worker metadata backend v1

`Backend(deadline_ns, clock=..., pidinfo=..., rusage=..., sysctl=..., platform=...)` directly observes explicitly supplied process metadata. It creates no process, inventory, pipe, signal, provider request or configuration. The caller supplies the original trusted absolute monotonic deadline, not a new TTL. Deadline/clock values are signed64-bounded and initial remaining time at most120seconds. Initial checks occur before native loading, with retained-deadline checks around each loader/prototype boundary; ordinary setup errors become finite native_unavailable. Missing Build policy and full supervisor/resource/launch-budget joins remain held. Receipt flags are all false. Host pressure elevated can be observed; it grants no launch admission.

Fixed layouts derive from published standalone organ guard SHA289643f5955ec243564728bf952e36e768cc8cb20430aa3d64766a4b674ab478 ABI patterns and local CommandLineTools SDK headers `sys/proc_info.h`, `sys/resource.h`, `sys/proc.h`, and `libproc.h`. No private imports or organ policy are copied. BSD/task sizes136/96, BSD start offsets120/128, taskRSS offset8 and rusageV0 size96/physical72/start80/exit88 are checked before queries. BSD flavor3/task flavor4 must return exact sizes; rusage flavor0 must return exact int0 with nonzero start and zero exit. SDK statuses2/3 map live and4 stopped; other states hold. Native structs include opaque process-name storage required by ABI but it is ignored and never projected. No argv/environment is read.

`identity(pid,uid)` returns PID/UID/birth/parent/state after exact-size validation. `sample(expected)` checks the retained closed trusted identity before/after task/rusage calls and retains the first kernel-start per target. SamePID replacement cannot overwrite retained birth; at most two successful target identities are retained. The trusted caller must restrict queries to original creator/target and preserve expected owner identity; this interface is not authenticated process authority and does not implement parentage/execution permission. It observes memory, not enforces a limit. Initial calibration caps remain unmeasured and are not paid-worker capacity.

`pressure()` accepts only exact native result0, integer-size readback and levels1 normal/2 or4 elevated; all other results unavailable. Call failures hold with finite diagnostics. Every syscall has original retained deadline checks before and after; synchronous ctypes calls cannot be preempted, so no hard wall guarantee is claimed. Linux is explicitly unsupported here; there is no ps capture or fabricated physical zero. Injected native functions must be supplied together or not at all; no partial injection silently invokes a real backend.

Fixtures mock size/result/state/identity/kernel-start/pressure/deadline failures, then inspect only the test process via direct libproc/sysctl. That test launches no worker and emits no PID/birth/raw metadata. It establishes current-process ABI viability only, not stopped-child, model-memory, cleanup or live Build acceptance. Actual supervisor inventory, host-pressure gates, stopped bootstrap, signals and cleanup, finite captures, app-server transport and original launch-ACK joins remain separate reviewed work.
