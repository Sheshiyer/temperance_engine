# Pure private actor context v2

`private-actor-context.py` implements pure framing, normalization and comparison only. No descriptor, filesystem, clock callback, native query, budget mutation, process, signal or model operation occurs. FD7 is a future child-input capability contract, not implemented transport. Existing v1 helper bytes and HANDLE/ACK fields remain unchanged.

Schema `temperance.private-actor-context.v2` has 15 base keys for role `original-owner-to-supervisor`; role `supervisor-to-worker` has the same base plus supervisor, exactly16. Base keys are schema,role,directory,creator,create_receipt,supervisor_reservation,worker_reservation,handle,created_ns,invocation_deadline_ns,exchange_deadline_ns,marker and3falseauthorityflags. Opaque kernel_start_token does not invent time-unit or native provenance.

Both original reservation responses must be present before either role is promoted. Existing10key handle has expected_counter0 for supervisor and1 for worker, same directory/nonce/limit/anchors. This codec does not reserve again, use the v1 counter0-only profile for worker2, extend ACK, or authenticate packet-selected identity. Marker onlyinert-metadata-bootstrap-v2. Trusted suppliednow is created<=now<exchange, with fragment times nondecreasing. Role handle clocks match enclosing original clocks exactly. No exchange renewal at supervisor/worker creation: an expired original exchange holds. Trusted reported time is not actual freshness/native attestation.

`encode_frame(context,now_ns)` validates bounded closed scalar shapes, then computes a conservative escaped literalUTF8 JSON aggregate<=16KiB before detached copies/serialization (`ensure_ascii=False`). `decode_payload(raw,expected_context,now_ns)` separately snapshots trusted expected context and requires exact equality after wire normalization. The packet cannot select its own expected role/creator/nonce/authority. Result is detached immutable nested private mappings, not a public projection.
