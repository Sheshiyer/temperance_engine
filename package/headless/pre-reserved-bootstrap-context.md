# Pure pre-reserved bootstrap context codec

`pre-reserved-bootstrap-context.py` encodes/decodes only detached trusted DTOs and injected byte fragments. It opens no FD, reads no clock callback, mutates no budget and creates/signals no process. Fixed child-role FD7 is a future adapter contract, not implemented transport.

Fixed two-level copies and a conservative escaped literalUTF8 JSON size calculation bound serialization≤16KiB, `ensure_ascii=False`. No arbitraryMapping/get/str/serializer callbacks. Caller concurrently mutating a trusted DTO is not a hostile shared-memory exclusion contract.

Node count covers containers/keys/scalar tokens. JSON object-pair parsing recursively rejects duplicate keys before closed-schema promotion; malformed/unknown/type/expiry failures remain finite heldcodes. Integer/bool identity stays exact. Decode returns immutable outer/nested mappings containing private context, never a public projection receipt.

ContextFrame admits one 4-byte big-endian length prefix plus exact payload and explicit EOF from injected bytes only. It bounds before append; partial/extra/oversize/error permanentlyholds, clears privatebuffers and never accepts a replacement frame. Fresh suppliednow atEOF checks expiry; monotonic fragment times cannot go backward. Successful decodedcontext requires EOF and clears bufferedbytes; repeat consumption holds. It infers no writer/native child completion from the caller's EOF assertion.

Cooperative owner-selected channel capability is not issuer/nativeharness authentication. Existing ACK has no childtoken: nativechildbirth/directparent/resources must later be separately retained and observed before ownerconfirmation. This pure codec cannot grant process/capacity/inference authority. Actual FDtopology/collision handling, orphan containment/parentloss, supervisor memory/OSlaunchaccounting and nativefixedbootstrap are unresolved; no SIGSTOP self-expiry claim or organguardpolicy reuse follows.

The frame caller owns its loop/deadline while context is incomplete; feed is not a timer or hard containment boundary. Reported fragment time alone cannot guarantee prompt future input or native scheduling.
