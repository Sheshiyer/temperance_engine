# Pure original-owner pre-reserved codec profile

`launch-pre-reserved-profile.py` joins trusted injected owner callbacks, not actual native ownership. It receives an already created budget receipt at counter0, an independently supplied original creator token, canonical directory and original monotonic deadlines. It never creates a budget, nonce or process, reads disk, refunds a slot or selects an FD.

Exact plain closed dict records are copied into immutable retained state before callbacks. Strings and numbers use the published codec/budget limits: directory4096UTF8bytes, nonce32lowerhex, Darwinbirth48ASCIIbytes, integerPID/UID, signed64 deadlines, limit1..4, strictcounter0→1, three authority flags exactlyFalse. Fixed containers have at most10keys each, depth2 and at most16KiB of bounded scalar encoding; there is no arbitrary mapping or stringify traversal. Caller DTOs/clock/callbacks remain trusted inputs, not hostile top-level authentication.

`reserve_and_create` observes the first creator token, marks reservation intent before the injected reservation callback, validates and retains exact reservedcounter1, reobserves creator, then marks create intent before injected create callback. ExactTrue and unchanged creator establish only an injected creation observation. Errors, lost/late results and duplicates permanently hold; uncertainty may have consumed the slot even when no reservation response was retained. No retry or diskcounter recovery occurs.

The existing codec child `reserve` callback can deliberately be this profile's once-only `receipt_supplier`, with a plain detached received handle. It compares all exact original handle fields and returns the already-retained receipt, making no second reservation mutation. Existing owner `retain_ack` callback can call the profile's `retain_ack(ack, ack_eof_retained)` only after codec ACK/EOF validation; it returnsNone. ACK has no directory; directory correlation stays in the independently retained original handle. Trusted EOF input is not native channel proof. Missing/contradictory ACK holds with no new confirmation permission.

The exchange deadline is captured before creation, at most2seconds from retained original created_ns and no later than original invocation deadline at most120seconds from the same anchor. No child deadline reset. Each callback has before/after checks; synchronous callback execution cannot be preempted. Error diagnostics are fixed finite codes and never invoke exception __str__.

A real native private-channel transfer of the pre-reservation receipt to the bootstrap remains unimplemented. Same-process synthetic callbacks do not prove issuer authenticity, original PID/birth, private FD3/4 ownership, child startup or resource admission. Slot counts the designated payload CLI launch in this profile; it does not automatically count bootstrap OS process creation or internal model turns. All authority/capacity/inference flags stayfalse; Build caps and actual activation remain held.

`TrustedCodecBridge` accepts only exact dict or MappingProxyType at the explicitly trusted existing codec callback seams, copies bounded scalar fields, and rejects generic Mapping. The backing mapping must be codec-owned plain data; exact proxy type does not authenticate its origin. Child reserve bridge supplies retainedreceipt; owner retain bridge has the existing singleargument signature and supplies the trusted EOF precondition solely from owner_exchange calling after its validated ACKEOF stage, never from wire metadata. An injected Channel fixture exercises both actual published exchange functions without FD actions.

The16KiB encoding upper bound describes literal UTF8 JSON (`ensure_ascii=False`) with control/quote/backslash escaping, not default ASCII-escaped serialization. No whole-object serializer is invoked by the bridge.
