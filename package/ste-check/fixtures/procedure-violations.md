# Bad procedure

You should check the valve; then you'll remove the cover.

The operator has adjusted the linkage and the filter must be replaced by the technician before the system is being started again by anyone.

The pump was installed by the team. The cover can be removed.

- Don't touch the connector.
- Make sure that you are checking the pressure.
- Configuring the router is optional.

It may fail. It might stop. You would see an alarm. It could restart. The fan will start. The relay closes. The light comes on. The cycle ends.
