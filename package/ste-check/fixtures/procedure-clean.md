# Replace the filter

Before you start the procedure, stop the pump.

1. Set the switch to OFF.
2. Remove the four bolts from the cover.
3. Remove the filter.
4. Install the new filter.

If the light comes on, stop the engine.
Refer to [the manual](https://example.com/manual) for the torque values.

```sh
pump --stop
```

Run `pump --start` to start the pump again.
