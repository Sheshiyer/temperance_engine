# RO-02 completion: routing-observation contract parity

## Outcome

Added the source-owned synchronizer and byte-identical router/Manifest bridge
repository copies of the canonical routing-observation receipt contract. The
copies are source artifacts only; they are not imported by a runtime consumer
in this slice and are not an installation or bridge-admission receipt.

## Source changes

- scripts/sync-routing-observation-contract.mjs is the exclusive source writer
  for the two declared copies. Default and explicit check modes are read-only;
  write mode is explicit and uses fixed paths derived from the script location.
- The synchronizer validates canonical ownership and static dependency edges,
  source/target/ancestor geometry, raw-byte equality and 0644 modes. It
  stages output, verifies each replacement and restores an earlier target for
  a caught later publication failure without claiming crash-atomic two-file
  publication.
- Generated byte-identical TypeScript copies now exist under package/router
  and package/manifest-bridge/src. The canonical source notice and structural
  schema wording describe those RO-02 copies accurately.
- tests/sync-routing-observation-contract.test.ts uses synthetic temporary
  roots to cover check/write behavior, mode and raw-byte drift, unsafe file
  geometry, import edges, rollback cleanup, detached imports and CLI location
  behavior.
