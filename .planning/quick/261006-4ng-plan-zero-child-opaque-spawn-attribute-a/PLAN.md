## Primary provenance freeze (read-only, before code)

Official Apple archived Darwin contracts are now read:
- [addclose/adddup2](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/posix_spawn_file_actions_addclose.3.html): both functions add operations to an action list for subsequent posix_spawn/spawnp use. Descriptor close/duplication effects concern the subsequently created child, not immediate modification of callerFDs. This supports zerochild DUP2(0,0)+CLOSE(0) storage-only test; no spawn consumes list here. Error return is an errno number, success0.
- [file actions init/destroy](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/posix_spawn_file_actions_init.3.html): init prepares an empty opaque action object; destroy releases resources of a previously initialized object. Reuse after destroy needs reinitialization, which this once-only test prohibits.
- [attributes init/destroy](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/posix_spawnattr_init.3.html): init prepares opaque attributes; destroy returns resources from a previously initialized object. Nonzero result is failure; unknown/nonzero init does not prove valid-object destruction eligibility.
- [flags get/set](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/posix_spawnattr_getflags.3.html): int-return APIs set/get short flags on the attributes object. Archived docs describe START_SUSPENDED child behavior but this zerochild point does not validate that behavior. CurrentSDK supplies numeric CLOEXEC_DEFAULT/SETSID extension constants; no archive/current-runtime equivalence inferred.
