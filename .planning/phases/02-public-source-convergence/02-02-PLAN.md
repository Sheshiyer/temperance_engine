## Task 1: Execute full-surface scan and author CANDIDATE-INVENTORY.md (type: execute)

**Files:** new `.planning/phases/02-public-source-convergence/CANDIDATE-INVENTORY.md`.

**Action:**
1. Enumerate candidate surfaces mechanically first (do not hand-wave the coverage set):
   ```bash
   ls -d package/*/ skills/*/ scripts/*.sh templates/* bin/* 2>/dev/null
   ```
2. For each surface, determine from its source/docs:
   - **Capability** — one-line description.
   - **Ships via** — the install-surface fragment carrying it (`hooks.json` / `router.json` / `manifest.json` / `enrichment.json` / `skills.json`) or `repo-native`.
   - **Class** — COPY (shipped verbatim), TRANSFORM (rendered through an allowlisted adapter), REGENERATE (host-derived at install), NEVER-SHIP (symbolic exclusion only).
   - **Private deps** — none, or the symbolic NEVER-SHIP boundary it depends on.
3. Write one row per surface. Coverage rules:
   - Every directory from step 1 appears exactly once; zero unmapped public capability.
   - Relocation tooling appears exactly once as NEVER-SHIP, documenting its overlay exclusion (Plan 01).
   - `atlasRecall.ts` appears NOWHERE in the inventory (it was never in the public payload); do not name it even as an example.
4. Add a short header stating scan date, enumeration command used, and total row count.
